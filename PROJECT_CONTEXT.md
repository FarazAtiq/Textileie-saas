# TextileIE Project Context

## Project

TextileIE is a cloud-based Industrial Engineering and ERP platform for textile and garment manufacturers.

## Objective

Digitize engineering, planning, costing, inventory, production, and reporting in a single integrated platform.

## Technology Stack

- React
- Vite
- Supabase
- PostgreSQL
- Vercel

## Design Principles

- Modern enterprise UI
- Reusable components
- Mobile responsive
- Consistent design
- Fast performance

## Core Principle

Engineering information is entered once and reused throughout the system.

## Main Modules

- Onboarding
- Organization
- Masters
- Style Master
- Engineering
- Export Orders
- Material Planning
- Purchasing
- Inventory
- Production
- Quality
- Reports
- AI
